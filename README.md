# CampusTrace

CampusTrace is a MERN Stack Lost & Found web application designed to help users report, search, and recover lost items.

## Features

* User Registration & Login
* JWT Authentication
* Add Lost/Found Items
* View All Items
* Search Items
* Filter by Category and Status
* Edit and Delete Posts
* Mark Items as Recovered
* Image Upload Support
* Responsive Modern UI

## Tech Stack

### Frontend

* React
* Vite
* React Router DOM
* Axios
* CSS

### Backend

* Node.js
* Express.js
* JWT
* bcryptjs

### Database

* MongoDB
* Mongoose

### Other Tools

* Cloudinary

## Project Purpose

This project was built to practice full-stack web development using the MERN stack. It demonstrates authentication, CRUD operations, REST APIs, database integration, image uploads, protected routes, and responsive UI design.
